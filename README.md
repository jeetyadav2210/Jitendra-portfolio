## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/jeetyadav2210/Jitendra-portfolio.git
cd Jitendra-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

```bash
npm run build
npm run start
```
